# Billionaires-Statistics-Analysis

# Summary of the Report

This project involved analyzing the world's billionaires dataset using Power Query for data cleaning and transformation, followed by descriptive and statistical analysis to extract key insights.

**Key Aspects of the Analysis:**

1. **Data Cleaning & Preparation:**

Used Power Query to clean, filter, and structure the raw dataset, ensuring accuracy for analysis.

2. **Descriptive & Statistical Analysis:**

Identified the top 10 richest billionaires globally based on net worth.

Analyzed the age distribution of billionaires, calculating the age gap between the youngest and oldest.

Examined wealth distribution across different industries and regions.

Assessed gender diversity and trends in billionaire demographics.

3. **Insights & Visualizations:**

Created charts, histograms, and summary tables to present findings effectively.

Discovered patterns in net worth variations, industry dominance, and geographical wealth concentration.
